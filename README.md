# 华东口岸报关看板

美的业务海关申报数据可视化看板，用于口岸单位每日导入 Excel 报表，领导查看业务量趋势和异常跟进。

## 使用方法

1. 用浏览器打开 `index.html`
2. 点击右上角「导入 Excel」按钮，选择 `华东口岸申报日报关情况 X.X.xlsx` 文件
3. 看板自动解析数据并展示

## 功能模块

### 1. KPI 概览卡片
- 累计申报总单量（所有日期的应申报总单量之和）
- 最新日申报单量（最新数据日的业务量）
- 本月申报单量（当前月份累计）
- 当前未放行单量（最新一天未放行原因中的总条数）
- 未闭环异常数（异常跟踪表中未闭环记录数）

### 2. 业务量趋势图
- 每日业务量折线图（近 90 天）
- 每月业务量柱状图

### 3. 未放行异常跟进
- 五个维度卡片：空运、驳船、大船、公路、查验
- 每个卡片显示未放行单量
- 点击卡片展开明细（单号 + 原因 + 关联异常记录）

### 4. 异常跟踪表
- 支持按事业部、异常类别、闭环状态筛选
- 支持关键词搜索（报关单号/提运单号/描述）
- 汇总统计：各异常类别数量、各事业部数量、闭环率
- 点击「展开」查看完整处理进度

### 5. 年份切换
- 支持 2025 / 2026 年数据切换
- 数据存储在浏览器 localStorage 中，刷新不丢失

## 数据格式要求

Excel 文件需包含以下 Sheet：
- `XXXX 日报关情况` — 日期、应申报总单量、已放行单量、审结、未放行原因
- `XXXX年异常跟踪表` — 异常记录明细
- `Sheet3` — 经营单位 → 事业部 → 通关代表 映射表

## 技术支持

纯前端应用，使用 CDN 加载：
- SheetJS (xlsx) — Excel 解析
- Chart.js — 图表渲染
